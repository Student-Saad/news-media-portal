## ⚡ দ্রুত শুরু (৫ মিনিটে)

### ১️⃣ MongoDB চালু করুন

```bash
# Windows: MongoDB কমিউনিটি ডাউনলোড করুন এবং ইনস্টল করুন
# Linux: sudo apt-get install -y mongodb
# macOS: brew install mongodb-community
```

### ২️⃣ ব্যাকএন্ড চালু করুন

```bash
cd /home/saadi/newspaper/news-media-portal
npm run dev
# সার্ভার চলবে: http://localhost:5000
```

### ৩️⃣ ফ্রন্টএন্ড চালু করুন (নতুন টার্মিনালে)

```bash

# অ্যাপ চলবে: http://localhost:5173
```

## 📚 এপিআই এন্ডপয়েন্টস

### অথেন্টিকেশন
```
POST   /api/auth/register      - নতুন ব্যবহারকারী
POST   /api/auth/login         - লগইন
GET    /api/auth/profile       - প্রোফাইল দেখুন
PUT    /api/auth/profile       - প্রোফাইল আপডেট করুন
```

### নিউজ আর্টিকেল
```
GET    /api/articles           - সব নিউজ (ফিল্টার সহ)
GET    /api/articles/:id       - একটি নিউজ
POST   /api/articles           - নিউজ তৈরি করুন
PUT    /api/articles/:id       - নিউজ আপডেট করুন
DELETE /api/articles/:id       - নিউজ ডিলিট করুন
POST   /api/articles/:id/like  - লাইক/আনলাইক
```

### মন্তব্য
```
GET    /api/comments/article/:articleId  - মন্তব্য দেখুন
POST   /api/comments/article/:articleId  - মন্তব্য তৈরি করুন
PUT    /api/comments/:id                 - মন্তব্য আপডেট করুন
DELETE /api/comments/:id                 - মন্তব্য ডিলিট করুন
POST   /api/comments/:id/like            - মন্তব্যে লাইক দিন
```

## 🐛 সাধারণ সমস্যা ও সমাধান

### ❌ "Cannot connect to MongoDB"
```bash
✅ MongoDB সার্ভার চালু করুন এবং রান করছে কিনা চেক করুন
mongosh  # MongoDB শেল খোলার চেষ্টা করুন
```

### ❌ "Port 5000 already in use"
```bash
# Linux/macOS
lsof -i :5000
kill -9 <PID>

# Windows
netstat -ano | findstr :5000
taskkill /PID <PID> /F
```

### ❌ "CORS error"
```
✅ .env ফাইলে JWT_SECRET পরিবর্তন করুন
✅ ব্যাকএন্ড এবং ফ্রন্টএন্ড উভয়ই চলছে কিনা চেক করুন
```
